This repository is a comprehensive engineering workspace dedicated to Full Stack software development. It serves as a centralized, multi-language sandbox for testing architectures, building APIs, exploring new frameworks, and solidifying backend and frontend mechanics without polluting production environments.

## 🗂️ Repository Architecture & Scope

To maintain isolation between different runtime environments and package managers, this workspace is heavily modularized by technology. Each directory acts as an independent learning environment:

* **🖼️ Frontend Ecosystem:** 
  * `vanilla-web/`: Fundamental DOM manipulation, HTML5, CSS3, and raw JavaScript logic.
  * `react/`: Component-based architecture, hooks, and state management.
  * `angular/`: Enterprise-level frontend structures and TypeScript integration.
* **⚙️ Backend & APIs (JavaScript/TypeScript):** 
  * `node-js/`: Express servers, RESTful APIs, and asynchronous event-driven scripts.
  * `nest-js/`: Scalable backend applications utilizing decorators and dependency injection.
* **🐘 PHP Architecture:** 
  * `php/`: Core PHP mechanics, OOP, and raw database connections (PDO).
  * `laravel/`: MVC architecture, ORM (Eloquent), and routing.
* **☕ Object-Oriented Core:** 
  * `java/`: Strongly typed OOP fundamentals and algorithmic challenges.

## 💻 Tech Stack Highlights

* **Frontend:** HTML5, CSS3, JavaScript (ES6+), TypeScript, React, Angular, Bootstrap, Tailwind CSS.
* **Backend:** Node.js, NestJS, PHP, Laravel, Java, C#, Flask.
* **Databases:** MySQL, SQLite.
* **Version Control & Tooling:** Git, GitHub, npm, Composer.
